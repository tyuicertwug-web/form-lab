# FORM / LAB — веб-приложение для iPhone

## Что это
Прогрессивное веб-приложение (PWA): открывается в Safari и может быть добавлено на экран «Домой». Анкета, список тренировок и отметки сохраняются локально в браузере. Нет сервера и учётной записи.

## Как открыть
Чтобы установить на экран «Домой», сайт должен быть опубликован по HTTPS. Самый простой способ с iPhone — загрузить эти файлы на статический хостинг (например, GitHub Pages или Netlify) через их веб-интерфейс, затем открыть опубликованный адрес в Safari → «Поделиться» → «На экран Домой».

В архиве есть index.html, manifest.json и icon.svg. Для предпросмотра можно открыть index.html, но установка как PWA требует публикации по HTTPS.

## Ограничения
Это MVP с правилами, а не медицинская или ИИ-оценка. Поле ограничений не меняет упражнения автоматически. Данные сохраняются локально в браузере и могут быть потеряны при очистке данных Safari.
