# GYMPLAN

Обновлённая версия веб-приложения для тренировок, футбольной подготовки и расчёта КБЖУ.

## Публикация на GitHub Pages
Загрузите `index.html`, `manifest.json` и `icon.svg` в корень репозитория и подтвердите Commit changes.

## Важно
Расчёты КБЖУ являются оценочными. Для несовершеннолетних приложение не назначает дефицит или профицит калорий. Данные сохраняются локально в браузере, если не подключена серверная авторизация/синхронизация.
