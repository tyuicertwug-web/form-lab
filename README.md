# IRON PLAN V5 — Football + Gym

Mobile-first static web app. Upload the contents of this folder to the root of your GitHub Pages repository, replacing `index.html`, `manifest.json`, and `icon.svg`.

## V5 changes
- Removed all exercise-bike references; warmups use walking and dynamic mobility.
- Added muscle-group focus: full body, upper/lower body, chest, back, shoulders, biceps, triceps, arms, core, push and pull.
- Added week/variation refresh button and three rotating training emphases.
- Added longer multi-exercise workouts with checkboxes and a one-tap diary entry.
- Nutrition goal choices: recomposition, fat loss, muscle gain, fat-mass gain, maintenance; calculations remain estimates.
- No squats, conventional deadlifts, or Romanian deadlifts in the program.

## Important
This is a static web app. Profile and logs are stored in local browser storage on the current device. Google login/cloud sync are not configured. For users under 18, the nutrition calculator avoids prescribing calorie deficits/surpluses; discuss weight goals with a clinician or sports dietitian.
